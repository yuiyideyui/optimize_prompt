# Image Counter

**图像批次计数节点**

统计输入的图像批次数量，返回图像的总数。这是一个简单但实用的工具节点，常用于调试、条件判断和流程控制。

## 分类

`my_comfyui/utils`

## 输入参数

| 参数名 | 类型 | 是否必需 | 说明 |
|--------|------|----------|------|
| `images` | `IMAGE` | ✅ | 输入的图像批次 |

## 输出

| 输出名 | 类型 | 说明 |
|--------|------|------|
| `count` | `INT` | 图像批次中的图像数量 |

## 功能说明

这个节点接收一个图像批次（IMAGE batch），返回该批次中包含的图像数量。在 ComfyUI 中，图像通常以 `[N, H, W, C]` 的张量形式存在，其中 N 是批次大小，该节点返回的就是 N 的值。

### 典型应用场景

1. **调试工作流**：快速检查某个节点输出了多少张图像
2. **条件判断**：根据图像数量决定后续处理流程
3. **批次验证**：确认批次大小是否符合预期
4. **循环控制**：在需要知道迭代次数的场景中使用

## 使用示例

### 示例 1: 基础计数

```
[Image Batch] → [Image Counter] → count: 4
```

输入 4 张图像，输出数字 4。

### 示例 2: 配合条件节点

```
[Load Image Batch] → [Image Counter] → count
                                         ↓
                                    [Math Compare]
                                         ↓
                                    根据数量执行不同逻辑
```

根据图像数量动态调整后续处理逻辑。

### 示例 3: 调试管线

```
[某个处理节点] → [Image Counter] → 显示数量
                ↓
            继续处理
```

在管线中间插入计数节点，确认某一步输出的图像数量。

## 技术细节

- **实现方式**：使用 Python 的 `len()` 函数获取图像批次的第一维度大小
- **性能**：O(1) 时间复杂度，几乎无性能开销
- **兼容性**：适用于所有 ComfyUI 图像格式

## 注意事项

- 该节点只统计批次数量，不检查图像内容、尺寸或有效性
- 输入必须是有效的 IMAGE 类型，否则会报错
- 输出的是批次大小，不是像素数或通道数

## 常见问题

**Q: 为什么我的单张图像也返回 1？**  
A: ComfyUI 中单张图像也是一个批次，批次大小为 1。

**Q: 能否统计多个输入的图像总数？**  
A: 该节点只接受单个 IMAGE 输入。如需统计多个输入，需要先用其他节点合并批次。

**Q: 输出能否用于数学运算？**  
A: 可以，输出类型是 INT，可以直接连接到需要整数输入的节点。

## 相关节点

- **Image Batch**: 将多张图像合并为批次
- **Image From Batch**: 从批次中提取单张图像
- **Math Compare**: 整数比较节点，可配合使用
